# Sebastian “Seth” Donea — personal site

My personal website: who I am and what I've built (PageMD, Helping Hands, Send Energy).

It's a work in progress. Right now the repo holds four design directions, and I'll build the final site from one of them.

| Direction | File |
|-----------|------|
| A: Notebook | `directions/a-notebook.html` |
| B: Poster | `directions/b-poster.html` |
| C: Room | `directions/c-room.html` |
| D: Your room | `d-your-room.html` |

## Running it

Everything is static HTML, CSS and JS. There's no build step and nothing to install. Open any file in a browser, or serve the folder:

```sh
python3 -m http.server
```
